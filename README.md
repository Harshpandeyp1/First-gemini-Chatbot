# First Gemini Chatbot 🤖

A simple AI chatbot built with **Node.js** and the **Google Gemini API**. This project demonstrates how to integrate generative AI capabilities into a JavaScript backend to handle conversational prompts and generate dynamic responses.

## ✨ Features
- Powered by the Google Gemini API
- Built with Node.js and JavaScript
- Simple and lightweight architecture for quick setup and experimentation
- Easy-to-configure environment variables for API key security

## 🛠️ Tech Stack
- **Runtime:** Node.js
- **Language:** JavaScript (100%)
- **AI Model:** Google Gemini (`@google/genai` or `@google/generative-ai`)
